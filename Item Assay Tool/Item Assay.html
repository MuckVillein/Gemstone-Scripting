~45 confirmed pairs as of live isolation batch (July 2026). Key finding: boost/req alone does NOT determine cost — same boost/req can differ by ability (Ranged Weapons +1/req2=1 vs Combat Maneuvers +1/req2=5), AND four abilities now show non-monotonic pairs where a HIGHER boost/req costs LESS than a lower one for the SAME ability (Magic Item Use +2→37 vs +3→14; Shield Use +2→20 vs +4→18; Spirit Mana Control +2→20 vs +3→8 from an earlier user item; Harness Power +2→20 vs +3→55, which goes the other direction). Four instances is too many to keep calling isolated anomalies — this is a real feature of the rank-enhancive Tier system, not noise. One caveat discovered mid-batch: items can carry seller-tagged temporary WPS ("temp. damage weighting") not reflected in structured fields, which contaminates isolation if not manually cross-checked against raw text (excluded several Ambush Ranks candidates for this reason).

Tier-group discovery (July 2026): user-provided GSWiki User:ZHEPHEN enhancive tier chart (2020) classifies abilities into tiers (e.g. Tier 7: Physical Fitness/Survival/Disarming Traps/Picking Locks/Stalking&Hiding/Perception/First Aid/Trading/Pickpocketing; Tier 10: Two Weapon Combat/Shield Use/Combat Maneuvers/Edged/Blunt/Two-Handed/Ranged/Polearm Weapons/Brawling/Ambush/Dodging/Spell Aiming/Harness Power/Elemental-Mental-Spirit Mana Control; Tier 14: Arcane Symbols/Magic Item Use/MOC). ZHEPHEN's stated formula (Trunc(level_req/3)) did NOT reproduce our confirmed values when tested directly — off by large, inconsistent factors. But the TIER GROUPINGS themselves are strongly confirmed: multiple different abilities in the same tier bucket produce IDENTICAL difficulty at the same boost/req (e.g. Shield Use +4/req20=18 = Two-Handed Weapons +4/req20=18; Brawling/Thrown Weapons/Spell Aiming all +6/req42=37; Stalking&Hiding/First Aid/Disarming Traps all +6/req30=25). The tool now uses this for tier-group fallback matching when an exact ability isn't in the lookup table.

Open gaps: Acuity and Dispel have official formulas (15/tier, 50+50×attempts) but no isolation data yet. Acid, Sonic, Steam, Unbalance, Water, Magma, Mechanical, Terror, and Holy Water flares have never appeared in a submitted item — no price data at all. Chronomage, Ironwright's, Poison, Rotating, and Rotflares scripts still aren't in the picker. Black alloy is a strong untested candidate for an 8th inherent-flare material (Shadowdeath flares are documented as exclusive to it, same pattern as gornar/zorchar/drakar/rhimar). Structural rule confirmed via GSWiki's Item Properties page (last edited Feb 15, 2026): shields can NEVER have damage padding, only critical.

Full re-verification against the official Script/Other Gear Difficulty Modifier tables (GSWiki, last edited Nov 19, 2024) confirmed the enchant formula exactly as used all along (ROUND(((Bonus-2)²)/9) — a player claim that it's linear "enchant ×5" is incorrect), resolved Clockwerke Weapon (T2 = 150, previously totally unknown), corrected Forest Armor to a flat 70 across all tiers (not scaled like Elven Armor — this retroactively solved a previously "impossible" T4 item), and confirmed Briar Flares T1/T2/T3 = 70/100/200 exactly, clearing Briar T3 of suspicion from two earlier messy items whose real problem was elsewhere.

Weapon-type inherent difficulty modifiers

Weapon typeModifierNotes
Claidhmore40 CER critical (baseline, squared like any WPS)Contributes trunc(40²)=1600 to difficulty. Up to 50 CER for legendary examples. Confirmed via GSWiki + an ~1,589-difficulty item with almost no other properties closing to an exact 40² remainder.
Katana10 CER critical (baseline, squared like claidhmore — trunc(10²)=100 to difficulty)Corrected framing: GSWiki's Tatterclaws' Comprehensive Gear Guide states directly "katanas have a natural 10 points of weighting," NOT a flat 100 difficulty add as first described (the arithmetic result is identical either way, trunc(10²)=100, but the correct unit is a CER baseline like claidhmore, not a flat surcharge). Confirmed via GSWiki User:ZHEPHEN's "Other Penalties" table (2020, unofficial) AND an item where subtracting exactly 100 resolved an otherwise-unexplained gap, making "It is NOT weighted... than a normal katana" mathematically consistent (remainder went to exact 0). Only katanas and claidhmores are confirmed to carry this — Tatterclaws' guide states "most weapons do not have inherent crit weighting" — so this should NOT be assumed for other weapon types (e.g. short swords) without their own confirmation.

Claidhmore and katana work differently: claidhmore's 40 is a CER baseline that gets squared like any other WPS value; katana's 100 is a flat addition to the difficulty subtotal, more like an inherent flare/script charge. Don't conflate the two when applying them. Worth checking other "notoriously heavy" or hybrid weapon types for similar undocumented baselines.

This case initially failed badly (naive deduction gave CER 14) because the item text "It has some unknown (scripted) benefit" was not detected — that phrase is standard boilerplate for ANY Category D script and does not mean unidentifiable; it means "look up the script's difficulty separately."
